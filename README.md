# James Mwai | Data Analyst portfolio

Live site: **https://emillio-james.github.io**

A single-page portfolio of my data cleaning, SQL and dashboard work, with links to the raw data, cleaned datasets and write-ups for each project.

## Projects on the site

| Project | Tools | What it shows |
|---|---|---|
| Nairobi farmer submissions | Python (pandas, NumPy) | 200 messy field submissions cleaned to 188 unique, analysis-ready rows |
| Mobile loan applications (Q2 2025) | OpenRefine, Python | Phone, date and amount formats standardised across 187 applications |
| Nairobi supermarket sales | OpenRefine, Power Query, Python | 300 transactions de-duplicated to 285, 55 product spellings merged into 22 |
| Telecom customer churn dashboard | Power BI | Who churns and what they have in common, so a retention team knows where to focus |
| Hospital and clinic databases | SQL | Relational schemas, joins and reporting queries |
| Used-car listings analysis | Excel | Pricing patterns explored with pivot tables and charts |
| Economic growth and household debt in Kenya, 2010–2023 | Research design | A study testing whether economic growth drove household borrowing |
